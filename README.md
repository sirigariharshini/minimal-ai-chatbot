# 🤖 Minimal AI Chatbot

A simple AI chatbot built using **Streamlit, LangChain, and Groq**. It supports conversational chat, conversation memory, streaming responses, and a clear chat option.

## 🛠️ Tech Stack

* **Python**
* **Streamlit** – Chat interface
* **LangChain** – LLM integration
* **Groq** – AI model inference
* **GPT-OSS-20B** – Language model
* **python-dotenv** – Environment variable management
